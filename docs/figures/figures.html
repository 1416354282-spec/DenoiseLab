DenoiseLab · 02 核心矛盾

SNR 最高的方法，未必是能用的方法

真实背景 · 眼电伪迹 · 注入 SNR −5 dB。每个点来自本工具的实际计算结果。

带通 / 陷波 小波 ASR ICA

DenoiseLab · 03 数据源设计

两套数据，只换背景这一个变量

算法、指标、导出完全相同；换数据源，才能看出结论是不是只在合成数据上成立。

合成 EEG

已知真值 · 可复现
  • 16 导 · 250 Hz · 40 s
  • α/β/θ 节律 + 1/f 背景 + 20 次 N400/P100
  • 四类伪迹按 −5 / 0 / +5 dB 注入
  • 固定随机种子，逐点真值可计算

真实背景 EEG

PhysioNet EEGBCI · ODC-BY 1.0
  • S001R02 眼闭静息，真实 1/f 与 α 峰
  • 0.5 Hz 高通 + 逐通道归一化
  • 160 → 250 Hz 重采样，取 40 s
  • 仅背景真实；伪迹与 ERP 仍为注入
真实 EDF→ 0.5 Hz 高通→ 逐通道归一化→ 160→250 Hz→ 注入伪迹 / ERP→ 构造真值
真实背景解决的是「背景像不像真 EEG」；它不代表真实伪迹、真实 ERP 或真实被试上的排名。

DenoiseLab · 05 指标体系

不是给一个总分，而是把代价摊开

七个指标分成三组：伪迹去了多少、信号留住了多少、下游还能不能用。

伪迹去了多少

SNR 提升↑
RRMSE↓

信号留住了多少

波形相关→ 1
α 功率保留→ 1
β 功率保留→ 1

下游还能不能用

ERP 峰值比→ 1
N400 潜伏期偏移→ 0 ms
综合分 = 波形相关 25% + N400 峰值 25% + 潜伏期 15% + SNR 15% + α/β 各 10%
权重可以换；页面始终把七个原始指标全部列出，不用一个分数替你下结论。
ERP 峰值比 < 70% 会触发「ERP / 语义实验慎用」警告；波形相关 < 0.8 会提示伪迹仍有残留。

DenoiseLab · 07 边界

这份结论能用到哪

把「能说明」和「不能说明」写清楚，比多给一个排名更有用。

能说明

方法特性与代价组合；同一数据下谁更保真；不同伪迹、不同 SNR 下的相对趋势。

不能说明

真实被试上的排名；真实伪迹的分布；去噪之后语义解码一定涨点。

怎么用

导出 MNE 脚本 → 在你的数据上复跑 → 先看 ERP 与下游任务，再决定是否采用。

两套数据的伪迹与 ERP 都是注入的，真值是构造的；ASR 为简化实现；深度去噪（如 GCTNet）未纳入本基准。
